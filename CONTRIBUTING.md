# Contributing

Contributions and bug reports are welcome. Keep the library independent of hardware vendors and external services. Use synthetic data in issues and tests; never submit real telemetry, machine names, IP addresses, tokens, or other sensitive data.

Run `npm install && npm run check` before a pull request. Include tests for boundary conditions, invalid input, and documented estimation assumptions.

Please avoid adding network access or runtime dependencies without explaining the need and the consequences for downstream users.
